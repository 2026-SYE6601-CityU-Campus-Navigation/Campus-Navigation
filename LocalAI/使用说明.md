# 本地生成式 AI 部署说明（LocalAI）

为城大校园导航项目的 **AI 路引模块** 提供本地推理兜底：一台普通学生电脑即可跑通的小型生成式 AI，全部文件放在 D 盘，不占用 C 盘空间。

## 目录结构

```
D:\CityUproject\LocalAI\
├── install_ollama.bat    一键安装入口（双击运行）
├── install_ollama.ps1    安装脚本本体（检测显存 → 装 Ollama → 拉模型 → 测试）
├── test_api.py           API 调用示例（生成一段路引）
├── active_model.txt      安装后自动生成，记录当前部署的模型名
├── models\               模型文件存放处（安装后自动生成，占用空间在此）
└── 使用说明.md           本文件
```

## 一键安装步骤

1. 双击 `install_ollama.bat`（无需管理员权限）。
2. 首次运行 Windows 防火墙会弹出网络提示，勾选「专用网络」并点「允许」。
3. 脚本会自动：下载 Ollama 安装包（约 1GB）→ 安装到 `D:\Ollama` → 把模型目录设为 `D:\CityUproject\LocalAI\models` → 检测显卡显存并拉取合适的小模型 → 跑一句测试。
4. 看到「===== 部署完成 =====」即成功。

## 显存与模型映射表

脚本自动检测显卡显存并按下表选择模型（均为 Qwen3，中文能力强，适合路引文案）：

| 检测到的显存 | 部署模型 | 说明 |
| --- | --- | --- |
| ≥ 12GB | qwen3:14b | 质量最好 |
| 6~12GB | qwen3:8b | 均衡之选 |
| 3.5~6GB | qwen3:4b | 轻薄本独显首选 |
| 1.5~3.5GB | qwen3:1.7b | 小显存 |
| 无独显/核显 | qwen3:1.7b | 纯 CPU 模式，内存 8GB 即可 |

> 检测不到 NVIDIA 显卡时按 CPU 模式处理；想换模型随时运行 `D:\Ollama\ollama.exe pull <模型名>` 并更新 `active_model.txt`。

## 使用方式

- **命令行**：`D:\Ollama\ollama.exe run qwen3:4b`（换成 active_model.txt 里的模型名）
- **HTTP API**：`http://localhost:11434`，兼容 OpenAI 风格 `/v1/chat/completions` 和原生 `/api/generate`
- **Python 示例**：`python D:\CityUproject\LocalAI\test_api.py 图书馆`（会生成一段从地铁站到图书馆的步行路引）

对接 AI 路引模块时，把「本地推理」这一级的 endpoint 指到 `http://localhost:11434` 即可，与云端可选方案形成三级降级。

## 常见问题

- **下载慢/失败**：Ollama 安装包和模型都在海外服务器，可挂代理重试；安装包下载失败直接重跑脚本。
- **静默安装没成功**：脚本会提示手动安装，运行下载好的 `OllamaSetup.exe`，安装目录选 `D:\Ollama`，装完重跑脚本即可（脚本会跳过已装好的部分）。
- **改了 OLLAMA_MODELS 但模型还是下到 C 盘**：需重启 Ollama（退出右下角托盘图标，脚本中已自动重启；若手动改环境变量，改完重启电脑最稳）。
- **AMD/Intel 显卡**：Ollama 新版对部分 AMD 卡支持有限，跑不动就用 CPU 模式（把模型换成 qwen3:1.7b）。
- **卸载**：退出 Ollama 托盘，删除 `D:\Ollama` 和 `D:\CityUproject\LocalAI\models`，并在系统环境变量里删掉 `OLLAMA_MODELS`。
